# Web OOP — Интерактивный мини-курс ООП для студентов КазНУ

Образовательный веб-проект (мини-LMS) для изучения Объектно-Ориентированного Программирования (ООП) студентами второго курса КазНУ. Проект разрабатывается совместно со студентами в рамках освоения ООП и практического агентного инжиниринга (Agent Engineering) по методологии Trace-First Workflow (TFW Full).

## North Star

<a id="ns1"></a>
### NS1 — Цель и назначение
Создать компактный, понятный и интерактивный веб-курс ООП на 2–3 недели (1 час лекций, 1 час практики, 1 час домашнего задания в неделю, финальный экзамен) на основе имеющихся учебных материалов кафедры. Студент должен удобно проходить курс от начала до конца, изучать теорию с визуализациями, выполнять интерактивные тесты, проверять код на практических заданиях и получать прозрачные баллы.

<a id="ns2"></a>
### NS2 — Принципы проекта
1. **Дружественность к ИИ-агентам:** лаконичный, известный, строго типизированный и неперегруженный технологический стек, в котором ИИ-агенты могут легко ориентироваться, писать чистый код, тестировать и дебажить.
2. **Прозрачность и самодокументируемость:** архитектура, ключевые процессы, структуры данных и UML-диаграммы подробно фиксируются в каталоге `docs/`.
3. **Локальная автономность:** сайт функционирует полностью локально, не требуя сложного внешнего деплоя и облачной инфраструктуры.

<a id="ns3"></a>
### NS3 — Non-goals (Чего мы НЕ делаем)
- Не создаём перегруженную корпоративную LMS с микросервисами и сложной распределённой авторизацией.
- Не используем тяжеловесные или экзотические фреймворки, усложняющие понимание и отладку для ИИ и студентов.
- Не требуем обязательного облачного деплоя.
