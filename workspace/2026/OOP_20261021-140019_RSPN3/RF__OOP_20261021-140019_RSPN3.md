## 5. Key Implementation Decisions

1. **Dual-field response**: Added `current_score` and `best_score` fields alongside legacy `score` field to maintain backward compatibility with existing tests.
2. **ContentService `get_practice()`**: Returns all JSON keys dynamically via a loop over known optional fields (`invariants`, `monolith_code`, `requirements`), avoiding hardcoded week-specific returns.
3. **`@lru_cache` for ContentService**: `get_content_service(week_number)` caches instances per week, avoiding re-instantiation.
4. **LectureRead idempotency**: `POST /mark-read` checks for existing record before insert; does not fail on duplicate calls.
5. **Progress summary**: `WEEK_CONFIG` list defines per-week parameters; easily extensible for Week 3+.
