## 5. Acceptance Criteria

### AC-1: Score desync fix (P1)

API responses для `POST /api/week1/practice/submit` и `POST /api/week2/practice/submit` содержат `current_score` (результат текущего запуска) и `best_score` (лучший сохранённый). UI показывает оба раздельно: текущий статус и лучший балл.

- [ ] При `failed` текущем запуске: `current_score=0`, `best_score` = предыдущий лучший
- [ ] При `passed` текущем запуске: `current_score=10`, `best_score` обновляется
- [ ] UI отображает текущий результат (passed/failed + current_score) и лучший балл отдельно

Gate: `pytest tests/test_api_week1.py tests/test_api_week2.py -v`
Evidence: Ручная проверка в браузере — submit failed code, verify UI shows failed + best score separately

### AC-2: Общая сводка прогресса (P5)

`GET /api/progress/summary?username=default_student` возвращает агрегированные баллы по всем неделям.

- [ ] Response содержит: `weeks[]` с баллами за quiz, practice, lecture_read по каждой неделе; `total_score`, `total_max`, `completion_percent`
- [ ] UI показывает секцию «Мой прогресс» с баллами по неделям

Gate: `pytest tests/test_progress.py -v`

## 6. Technical Guidance

- `ContentService`: использовать `__init__(self, week_number: int)`, путь `content/week{N}/`. Кеширование JSON — `@lru_cache` или чтение при инициализации.
- `LectureRead`: минимальная модель `(id, student_id, week_number, read_at)`. Автосоздание через SQLAlchemy `create_all()`.
- `progress.py`: новый router `prefix="/api/progress"`. Summary агрегирует `TopicProgress` + `LectureRead` по всем неделям.
- Export JSON: включить `student`, `date`, `weeks[{week, quiz, practice, lecture_read}]`, `total`, `max`, `percent`. Формат compact, one-message friendly.
- Logging: `@app.middleware("http")` или Starlette `BaseHTTPMiddleware`. Log level INFO для request/response, ERROR для exceptions.
- UI score desync: показывать `"Текущий результат: ❌ 0/10"` и `"Лучший балл: ✅ 10/10"` раздельно.
- UI export: `navigator.clipboard.writeText(JSON.stringify(data, null, 2))` с fallback `textarea.select() + document.execCommand('copy')`.

## 7. Definition of Failure

- ❌ Существующие тесты Week 1 или Week 2 не проходят после изменений (регрессия)
- ❌ Данные студентов теряются при перезапуске сервера
- ❌ Сервер не запускается после изменений
