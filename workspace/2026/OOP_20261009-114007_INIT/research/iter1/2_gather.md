### G2: Критерии дружественности к ИИ-агентам (AI-Friendliness)
- ИИ-агенты эффективнее всего работают со стеком, который:
  1. Имеет строгие, понятные контракты и автодокументацию (FastAPI Pydantic схемы генерируют OpenAPI `/docs`).
  2. Имеет детерминированные тесты без браузерных флаков (pytest с понятным выводом ошибок).
  3. Не требует тяжелой сборки (Webpack/Vite dev server с HMR часто зависает в фоновом терминале агента, тогда как FastAPI со статическими файлами или чистый HTML/JS работает мгновенно без npm install build loop).
  4. Компактен по кодовой базе (меньше файлов — меньше расход токенов контекста).
