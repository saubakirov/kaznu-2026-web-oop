## Findings

### E1: Анализ конфигурации C1 (FastAPI + Tailwind CDN + Mermaid.js)
1. **Единый язык стека и курса:** И курс, и бэкенд, и автотесты написаны на Python 3.12+. Студенты второго курса не путаются между синтаксисом бэкенда и предметной областью.
2. **Нулевой порог запуска (Zero-build):**
   - Фронтенд отдается как статические файлы через FastAPI (`StaticFiles(directory="static")`).
   - Tailwind подключается через CDN — верстка адаптивная, современная, красивая, но без сотен мегабайт `node_modules` и сборщиков Webpack/Vite.
   - Визуализации UML (диаграммы классов, последовательностей событий валидатора) рендерятся на клиенте с помощью библиотеки `mermaid.min.js`.
3. **Безопасная и быстрая проверка кода:**
   - Студент пишет или вставляет код прямо на веб-странице.
   - Бэкенд сохраняет код во временную песочницу и прогоняет изолированный набор тестов `pytest` с тайм-аутом (например, 5 секунд).
   - Результат (зеленые/красные тесты, баллы, лог ошибок) моментально возвращается в UI.
4. **Хранилище состояния:**
   - Легковесная SQLite база данных (через SQLAlchemy или SQLite3 stdlib) или структурированный JSON-стор (`data/progress.json`) для хранения профилей студентов, баллов и прогресса.

### E2: Структура каталога документации `docs/`
Для удовлетворения требования пользователя («Мне как человеку важно только знать и понимать как оно работает, следовательно все должно быть хорошо задокументировано здесь в папке docs, процессы архитектура, стек, UML диаграммы и т.д.»):
- `docs/architecture.md`: описание архитектуры мини-LMS, слоев, потоков данных, схемы API.
- `docs/domain_model_uml.md`: UML-диаграммы предметной области Avtobys (классы, интерфейсы, паттерны) в формате Mermaid.
- `docs/course_structure.md`: подробная разбивка 3 недель (лекция, практика, ДЗ, экзамен) с критериями баллов.
- `docs/agent_collaboration.md`: описание того, как ИИ-агенты и студенты развивают этот проект по методологии TFW.
